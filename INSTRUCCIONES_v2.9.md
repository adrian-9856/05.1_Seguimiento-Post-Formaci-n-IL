## 📋 INSTRUCCIONES DE INSTALACIÓN

### 1️⃣ COPIAR EL CÓDIGO

1. Abre tu Google Sheet
2. Ve a **Extensiones → Apps Script**
3. **BORRA** todo el código que aparece en el editor
4. **COPIA TODO** el contenido del archivo `CODIGO_COMPLETO_v2.9_FINAL.gs`
5. **PEGA** el código en el editor de Apps Script
6. **GUARDA** el proyecto (Ctrl+S o icono de disquete)

### 2️⃣ PRIMER USO

1. **Recarga** tu Google Sheet (F5)
2. Verás el menú **🎓 Sistema de Seguimiento** en la barra superior
3. Ejecuta: **🔧 Configuración → ⚙️ Configuración Inicial**
4. Espera a que se creen todas las hojas

---

## 🆕 ACTIVAR FUNCIONALIDAD v2.9 "NO TERMINÓ"

### Paso 1: Instalar
1. Menú → **🆕 No Terminó Formación**
2. Clic en **✨ INSTALAR Funcionalidad v2.9**
3. Clic en **SÍ** para confirmar
4. Espera a que se complete la instalación

### Paso 2: Usar
1. Ve a **📋 Seguimiento General**
2. En la **columna K** verás "No terminó formación (Sí/No)"
3. Para participantes que NO completaron, marca **"Sí"**
4. Ejecuta: **No Terminó Formación → 🔄 Mover Participantes**
5. ¡Listo! Los participantes se mueven automáticamente a la hoja **❌ No Terminó la Formación**

## 🎯 USO DIARIO

### Procesar Llamadas (Modo Automático)
1. Activa: **⚡ ACTIVAR Procesamiento Automático**
2. Marca los **checkboxes** de la columna "Procesar"
3. Espera 1-2 segundos entre cada checkbox
4. El sistema procesa automáticamente

### Procesar Llamadas (Modo Manual)
1. Marca los **checkboxes** que quieras procesar
2. Ejecuta: **🔄 Procesar Llamadas Marcadas**
3. Revisa el reporte de resultados

### Ver Abandonos
1. Menú → **🆕 No Terminó Formación**
2. Clic en **📊 Ver Reporte**
3. Verás lista de participantes que no terminaron

## ⚠️ SOLUCIÓN DE PROBLEMAS

### Problema: "Doble procesamiento"
**Solución:**
1. Menú → Reportes → **🔍 Diagnosticar Doble Procesamiento**
2. Sigue las recomendaciones
3. Si persiste: Mantenimiento → **🧹 Limpiar Bloqueos**

### Problema: "Falta columna K"
**Solución:**
1. Ejecuta: **No Terminó Formación → ✨ INSTALAR Funcionalidad v2.9**
2. Recarga la página (F5)

### Problema: "No aparece el menú"
**Solución:**
1. Recarga el Google Sheet (F5)
2. Si persiste, ve a Apps Script y guarda nuevamente (Ctrl+S)
3. Recarga el Sheet
